📚 HƯỚNG DẪN TỪNG BƯỚC Thời gian đọc: ~5 phút thực hành

Trong bài viết này, Nguyen Dang AI sẽ hướng dẫn bạn chi tiết cách kết nối n8n với OpenAI API và Google Sheets để tự động hóa việc phân tích và tóm tắt văn bản hàng loạt mà không cần viết code phức tạp.

1

Chuẩn bị API Key từ OpenAI Platform

Truy cập vào trang quản trị platform.openai.com, điều hướng đến mục API Keys và tạo một Secret Key mới. Nhớ lưu lại khóa này ở nơi an toàn vì nó chỉ hiển thị một lần duy nhất.

2

Khai báo Credentials trên n8n

Trong giao diện n8n, vào mục Credentials > New Credential, tìm kiếm OpenAI API và dán khóa API đã copy ở Bước 1 vào. Bấm Save để kiểm tra kết nối hợp lệ.

3

Tạo Node OpenAI và cấu hình Prompt

Thêm node OpenAI vào canvas của bạn, chọn resource là Chat và model là gpt-4o-mini để vừa tiết kiệm chi phí vừa cho tốc độ xử lý nhanh nhất.

💡 Mẹo tối ưu chi phí: Bạn nên đặt tham số max_tokens ở mức vừa phải (ví dụ 500 - 1000) và hạ temperature xuống 0.2 nếu cần kết quả trích xuất dữ liệu chính xác và không bị lan man.

Lệnh cài đặt n8n qua Docker (Nếu bạn tự host)

docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n:latest

Lời kết

Chỉ với vài thao tác cơ bản, bạn đã có thể tích hợp AI thông minh vào hệ thống tự động hóa của mình. Nếu gặp bất kỳ khó khăn nào trong quá trình thực hiện, đừng ngần ngại để lại bình luận bên dưới hoặc tham gia nhóm cộng đồng của chúng tôi để được trợ giúp!
