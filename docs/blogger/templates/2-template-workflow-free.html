1. Vấn đề quy trình này giải quyết

Trước khi áp dụng workflow, việc thao tác thủ công mất nhiều thời gian và dễ xảy ra sai sót. Quy trình này giúp bạn tự động hóa hoàn toàn từ khâu nhận dữ liệu, xử lý thông tin cho đến lưu trữ trên bảng tính Google Sheets.

2. Sơ đồ cấu trúc các Node trong n8n

  • Webhook: Tiếp nhận dữ liệu kích hoạt từ trình duyệt hoặc ứng dụng.
  • Code Node (JavaScript): Trích xuất và định dạng lại các trường thông tin cần thiết.
  • Google Sheets Node: Tự động thêm dòng mới hoặc cập nhật hàng tương ứng.

3. Hướng dẫn từng bước nhập vào n8n

  1. Mở ứng dụng n8n của bạn (Self-hosted hoặc n8n Cloud).
  2. Tạo một Workflow mới, chọn menu Workflows > Import from File hoặc nhấn phím tắt Ctrl + V dán mã JSON dưới đây.
  3. Kết nối tài khoản Google Sheets Credential của bạn.
  4. Bấm nút Test workflow để kiểm tra dữ liệu mẫu trước khi bật Active.
